\section{Introduction}

In this technical note I provide a taxonomy and construction of base
schemes for hyperbolic PDEs. In general, we can write such equations
(in 1D, with generalization to multiple dimensions being obvious) in
conservation law form
\begin{align}
  \pfrac{Q}{t} + \pfrac{F}{x} = s(Q). \label{eq:hyp-a}
\end{align}
Where $Q(x,t)$ is a vector of $m$ conserved quantities and $F(Q)$ is
the flux function.  Some systems, like acoustics in heterogenous media
can't be written in this form but instead as
\begin{align}
  \pfrac{V}{t} + A \pfrac{V}{x} = s(Q). \label{eq:hyp-b}
\end{align}
Hwre $A = A(Q)$ is a $m \times m$ matrix. We can always tranform
\eqr{\ref{eq:hyp-a}} into \eqr{\ref{eq:hyp-b}}, but the reverse is not
always possible. Ideally, we would like to be able to solve the
equation in either form. Hence, for some systems we not have an
explicit flux function. We will assume that the eigenvalues of the
flux Jacobian or the $A$ matrix are real and that there is a complete
set of eigenvectors

The function $s(Q)$ is some source term. Additional, higher-order
derivative terms can also be added to this basic form of the
equations.

\section{Exact Solution to 1D Linear Hyperbolic System}

Consider the one-dimensional system of equations
\begin{align}
\pfrac{Q}{t} + \pfrac{F}{x} = 0 \label{eq:hyp1}
\end{align}
Where $Q(x,t)$ is a vector of $m$ conserved quantities and $F(Q)$ is
the flux function. At first, let us assume the system is linear and
write the flux as
\begin{align}
F = A Q
\end{align}
where $A$ is a constant $m\times m$ matrix. We will assume that this
system is hyperbolic, i.e. the eigenvalues of $A$ are real and the
eigenvectors are complete. Let $\lambda_p$ be the eigenvalues and
$r^p$ and $l^p$, $p=1,\ldots,m$ be the right and left eigenvectors
respectively. We will represent right eigenvectors as column vectors,
and left eigenvectors as row vectors.

To solve \eqr{\ref{eq:hyp1}} we first convert it to a system of
uncoupled advection equations by multiplying it from the left by
$l^p$. This gives
\begin{align}
\pfrac{w^p}{t} + \lambda_p \pfrac{w^p}{x} = 0 \label{eq:wp-advect}
\end{align}
where we have defined the \emph{Riemann variables} $w^p = l^p Q$. Note
that given $w^p$ we can recompute $Q$ from
\begin{align}
Q = \sum_p w^p r^p. \label{eq:wp-to-Q}
\end{align}
A useful identity is
\begin{align}
\sum_p w^p \lambda_p r^p = \sum_p w^p A r^p = A \sum_p w^p r^p = AQ = F(Q). \label{eq:wp-ident1}
\end{align}

Now consider a domain $-\infty < x < \infty$ and the initial
conditions $w^p_0(x) = l^p Q_0(x)$. Each advection equation for the
Riemann variables can be solved exactly as
\begin{align}
w^p(x,t) = w^p_0(x-\lambda_p t)
\end{align}
From this, the exact solution to the linear system can be obtained as
\begin{align}
Q(x,t) = \sum_p w^p_0(x-\lambda_p t) r^p = \sum_p l^p Q_0(x-\lambda_p t) r^p.
\end{align}

\section{Basic Formulation of Finite-Volume Schemes}

The finite-volume (FV) scheme for the system \eqr{\ref{eq:hyp1}} is a
method to update the \emph{cell-average} of the solution in
time. Consider a cell $I_j \equiv [x_{j-1/2},x_{j+1/2}]$ with uniform
cell-spacing $\Delta x \equiv x_{j+1/2}-x_{j-1/2}$. Integrate
\eqr{\ref{eq:hyp1}} to get
\begin{align}
  \pfrac{Q_j}{t} + \frac{F_{j+1/2}-F_{j-1/2}}{\Delta x} = 0
  \label{eq:fv-exact}
\end{align}
where $Q_j$ are cell-average quantities
\begin{align}
  Q_j(t) = \frac{1}{\Delta x}\int_{I_j} Q(x,t) \thinspace dx
\end{align}
and $F_{j\pm 1/2} = F(Q_{j\pm 1/2})$ are the fluxes at the
\emph{cell-edges} $x_{j\pm 1/2}$. Notice that in effect finite-volume
scheme uses the \emph{mean flux gradient} in the cell
\begin{align}
  \frac{1}{\Delta x}\int_{I_j} \pfrac{F}{x} \thinspace dx =
  \frac{F_{j+1/2}-F_{j-1/2}}{\Delta x}.
\end{align}
to update the \emph{cell average} in time. This is a subtle point and
often the cause of misinterpreting the accuracy or order of a FV
scheme.

\begin{figure}
  \setkeys{Gin}{width=0.45\linewidth,keepaspectratio}
  \incfig{fv-lr-vals.pdf}
  \caption{Recovery is used to compute left/right values
    $Q_{i+1/2}^{\pm}$ from a set of cell-averages and are then fed
    into a numerical flux function to update the solution.}
  \label{fig:fv-lr}
\end{figure}

At this point the discrete expression is exact, but only formally:
given the cell-averages we can't uniquely determine the edge values
$Q_{j\pm 1/2}$ to insert into the edge fluxes. The FV scheme is an
approximation in which these edge values are \emph{recovered}
(approximately) from the cell-averages and then used in a
\emph{numerical-flux} to update the cell-average approximation. We can
write this as
\begin{align}
  \pfrac{Q_j}{t} + \frac{G(Q_{j+1/2}^+,Q_{j+1/2}^-) - G(Q_{j-1/2}^+,Q_{j-1/2}^-)}{\Delta x} = 0
  \label{eq:dq-dt}
\end{align}
where $G(Q_R,Q_L)$ the \emph{numerical-flux} function and
$Q_{j\pm 1/2}^+$ and $Q_{j\pm 1/2}^-$ are recovered values just the
right and left of the interface $j\pm 1/2$ respectively (see
Fig.\thinspace\ref{fig:fv-lr}). For consistency with the exact form
\eqr{\ref{eq:fv-exact}} we must ensure that the numeric flux is
Lipschitz continuous\footnote{This ensures that the derivative of the
  numerical-flux with each of its independent variables is
  \emph{bounded}.} and \emph{consistent}: when $Q_L = Q_R$ then
$G(Q_R,Q_L)$ must reduce to the physical flux function, i.e.
\begin{align}
  \lim_{Q_{L,R}\rightarrow Q} G(Q_R,Q_L) = F(Q).
\end{align}

\section{Computing the Numerical Flux}

Let us first consider a linear system in which we use the
cell-averages directly as the left/right edge values, skipping the
recovery step completely. This \emph{first-order} scheme for linear
equations will form the basis for higher-order schemes for nonlinear
systems. We will also use a simple forward-Euler time-stepper to
simplify the third-step.

Instead of directly discretizing the coupled system of equations (in
which upwind direction may not not be clear), we can instead solve the
linear advection equations for the Riemann variables using an upwind
method and the convert the solution for $w^p$ to $Q$ using
\eqr{\ref{eq:wp-to-Q}}. We can write a first-order upwind method for
the Riemann variables as
\begin{align}
w^{p,n+1}_j = w^{p,n}_j - \frac{\Delta t}{\Delta x}
\left(
G^p(w^{p,n}_{j+1},w^{p,n}_{j}) - G^p(w^{p,n}_{j},w^{p,n}_{j-1})
\right) \label{eq:wn1}
\end{align}
where the numerical flux function for the Riemann variables,
$G^p(w_R,w_L)$, is defined as
\begin{align}
G^p(w_R^p,w_L^p) = \frac{\lambda_p}{2}(w_R^p + w_L^p) - \frac{|\lambda_p|}{2}(w_R^p - w_L^p).
\end{align}
Note that this choice of flux ensures that if $\lambda_p>0$ then
$G^p(w_R,w_L) = \lambda_p w_L$ and if $\lambda_p < 0$ then
$G^p(w_R,w_L) = \lambda_p w_R$, ensuring proper upwinding of the
values at cell interfaces.

To understand the effect of unwinding we plug the expression for the
numerical flux into \eqr{\ref{eq:wn1}} to get
\begin{align}
w^{p,n+1}_j = w^{p,n}_j 
- \frac{\Delta t}{\Delta x}\frac{\lambda_p}{2} \left(w^{p,n}_{j+1}-w^{p,n}_{j-1} \right)
+ \frac{\Delta t}{\Delta x}
\frac{|\lambda_p|}{2} \left(w^{p,n}_{j+1} - 2 w^{p,n}_{j}  + w^{p,n}_{j-1} \right).
\end{align}
This expression shows that the spatial gradient is discretized using a
central difference, with an additional \emph{numerical diffusion}
term, the diffusion coefficient being $\Delta x|\lambda_p|/2$. Also
note that each Riemann variable has, in general, a \emph{different}
diffusion coefficient.

To convert this to a scheme for $Q$ instead, multiply by $r^p$ and sum
over $p$ to get
\begin{align}
Q^{n+1}_j = Q^n_j - \frac{\Delta t}{\Delta x}\left(G(Q^n_{j+1},Q^n_{j}) - G(Q^n_{j},Q^n_{j-1})\right).
\end{align}
The numerical flux $G(Q_R,Q_L)$ is computed from
\begin{align}
G(Q_R,Q_L) = \sum_p r^p G^p(w_R^p,w_L^p) = \frac{1}{2} \sum_p \lambda_p r^p (w_R^p+w_L^p) 
- \frac{1}{2} \sum_p |\lambda_p| r^p (w_R^p-w_L^p).
\end{align}
We can write the first term, using identity \eqr{\ref{eq:wp-ident1}}
as $(F(Q_R)+F(Q_L))/2$. To rewrite the second term introduce
\begin{align}
\lambda_p^+ &= \max(\lambda_p,0) \\
\lambda_p^- &= \min(\lambda_p,0).
\end{align}
Note that in terms of these we can write
$\lambda_p = \lambda_p^+ + \lambda_p^-$ and
$|\lambda_p| = \lambda_p^+ - \lambda_p^-$. Using the latter identity
the numerical flux can be written as
\begin{align}
G(Q_R,Q_L) = \frac{1}{2}\big(F(Q_R)+F(Q_L)\big) - \frac{1}{2}(A^+\Delta Q_{R,L} - A^-\Delta Q_{R,L})
\label{eq:num-flux-1}
\end{align}
where the \emph{fluctuations} $A^\pm\Delta Q$ are defined as
\begin{align}
A^\pm\Delta Q_{R,L} \equiv \sum_p r^p \lambda^\pm_p (w_R^p-w_L^p) = \sum_p r^p \lambda^\pm_p l^p(Q_R-Q_L). \label{eq:fluct}
\end{align}
The fluctuations satisfy the \emph{flux-difference} or
\emph{flux-jump} identity
\begin{align}
A^+\Delta Q_{R,L} + A^-\Delta Q_{R,L} = 
\sum_p r^p \underbrace{(\lambda_p^+ + \lambda_p^-)}_{\lambda_p}
(w^p_R-w^p_L) = F(Q_R)-F(Q_L). \label{eq:flux-jump}
\end{align}
Using this identity, the numerical flux can also be written as
\begin{align}
G(Q_R,Q_L) = F(Q_L) + A^-\Delta Q_{R,L} = F(Q_R) - A^+\Delta Q_{R,L}.
\label{eq:num-flux-2}
\end{align}

For further use, we will introduce the concept of a \emph{wave}. We
define these vectors as
\begin{align}
  \mathcal{W}_{R,L}^p \equiv r^p (w_R^p-w_L^p) =  r^p  l^p(Q_R-Q_L) .
\end{align}
We will arrange the waves such that the corresponding eigenvalues are
ordered, that is $\lambda^1 \le \lambda^2 \ldots \le \lambda^m$.

In terms of the waves the fluctuations, \eqr{\ref{eq:fluct}}, can be
computed as
\begin{align}
  A^\pm\Delta Q_{R,L} = \sum_p \lambda^\pm_p \mathcal{W}_{R,L}^p.
\end{align}
Note that if we sum all the waves we get
\begin{align}
  \sum_p \mathcal{W}_{R,L}^p = \sum_p r^p (w_R^p-w_L^p) = \sum_p  r^p  l^p(Q_R-Q_L) = Q_R-Q_L.
  \label{eq:state-jump}
\end{align}
That is, the sum of all the waves is just the jump in conserved
variables. We will call this the \emph{state-jump} identity.

We can now introduce \emph{intermediate states}, $Q_0^* = Q_L$,
$Q^*_1, \ldots, Q_{p-1}^*$ , $Q_m^* = Q_R$, such that
\begin{align}
  Q^*_p &= Q_{p-1}^* + r^p l^p (Q_R-Q_L)
\end{align}
for $p=1,\ldots,m$. In terms of these intermediate states the waves
can be written as
\begin{align}
  \mathcal{W}^p = Q_{p}^* - Q_{p-1}^*.
\end{align}

All the above manipulations were done for a system of linear
hyperbolic PDEs, in which the flux Jacobian does not depend on the
solution itself. However, for \emph{nonlinear} hyperbolic PDEs the
flux Jacobian \emph{does} depend on the solution. Now consider again
the two values $Q_{R,L}$ at each interface. Which one should we use to
compute the flux Jacobian and from that the eigenvalues and the
right/left eigenvectors?

Let us define an averaged state
\begin{align}
  \overline{Q} = \overline{Q}(Q_R, Q_L)
\end{align}
We can use this averaged state to compute the eigensystem of the flux
Jacobian. The key consistency constraint we must ensure is that the
\emph{flux-jump identity, \eqr{\ref{eq:flux-jump}}, must be
  satisfied}. We call an averaging procedure that satisfies the
flux-jump condition as \emph{Roe averages}. Clearly, simple arithmetic
averages may not work.

In the next section we describe an alternate procedure in which the
flux-jump condition is \emph{always satisfied} independent of the
choice of $\overline{Q}$ by redefining the waves and fluctuations.

\section{The $f$-wave Approach}

Coming up with a Roe averaging procedure for a complex, nonlinear
system of hyperbolic PDEs is not trivial. As an alternative we can
construct the waves and fluctuations in such a way that the flux-jump
condition is always satisfied independent of how $\overline{Q}$ is
defined. This allows, for example, using simnple arithmetic averages
instead. To do this, we redefine the waves as
\begin{align}
  \mathcal{Z}^p_{R,L} \equiv r^p l^p\left[ F(Q_R) -F(Q_L) \right].
\end{align}
Notice that we are projecting the jump in \emph{flux} rather than the
conserved variables in this expression. We call this approach the
\emph{$f$-wave approach} in contrast to the \emph{$q$-wave approach}
in which we split instead the jump in conserved variables. Also note
that in the $f$-wave approach the sum of all the waves is now the jump
in \emph{flux} and not the state variables.

Using these waves we now compute the fluctuations as
\begin{align}
  A^+\Delta Q_{R,L} &= \sum_{\lambda_p>0} \mathcal{Z}_{R,L}^p + \frac{1}{2} \mathbb{Z} \\
  A^-\Delta Q_{R,L} &= \sum_{\lambda_p<0} \mathcal{Z}_{R,L}^p + \frac{1}{2} \mathbb{Z}
\end{align}
where
\begin{align}
  \mathbb{Z} = \sum_{\lambda_p = 0} \mathcal{Z}^p_{R,L}
\end{align}
is the sum of all the eigenvectors with eigenvalue zero. Now, as we
split the jump in flux directly, the flux-jump condition is satisfied
\emph{by definition}, independent of what averaged state
$\overline{Q}$ we used in computing the eigensystem of the flux
Jacobian.

\section{Semi-Discrete Update Formulas}

\subsection{First-Order Scheme}

In a first-order scheme we take the solution to be piecewise
constant. With this ansatz we have that the values of $Q$ the left and
right edges of cell $j$ are the same:
\begin{align}
  Q_{j+1/2}^- = Q_{j-1/2}^+
\end{align}
With this, the semi-discrete scheme, \eqr{\ref{eq:dq-dt}}, on using
the flux-jump conditions, can be written in terms of the fluctuations
\begin{align}
  \pfrac{Q_j}{t} = -\frac{1}{\Delta x}\left( A^+\Delta Q_{j-1/2} + A^-\Delta Q_{j+1/2} \right).
  \label{eq:first-order}
\end{align}
Here, as described above the fluctuations must be computed (for a
nonlinear system) with Roe averages when using $q$-waves, and either a
Roe or arithmetic average with using $f$-waves.

\subsection{Higher-Order Schemes}

To construct a higher-order method we need to reconstruct a polynomial
in each cell using the cell averages in that cells and its neighboring
cells. We will describe this reconstruction process below. A second-
or higher-order reconstruction will mean the value of the recovered
polynomial, $Q_j(x,t)$, in the cell is, in general, different on each
edge of the cell $j$, that is $Q_j(x_{j+1/2},t) \ne
Q_j(x_{j-1/2},t)$. In this case we must use the general formulas for
the numerical flux \eqr{\ref{eq:num-flux-1}} or one of the pairs
\eqr{\ref{eq:num-flux-2}}. If we use the latter pair alternately in
the the semi-discrete scheme, \eqr{\ref{eq:dq-dt}} we will get
\begin{align}
  \pfrac{Q_j}{t}
  = 
  -\frac{1}{\Delta x}\left( A^+\Delta Q_{j-1/2} + A^-\Delta Q_{j+1/2} \right)
  -\frac{1}{\Delta x}\left[ F(Q_{j+1/2}^-) - F(Q_{j-1/2}^+)  \right].
  \label{eq:second-order}
\end{align}
The second term accounts for the variation of the flux inside the cell
itself and gives higher order solutions. Of course, this term vanishes
when the solution is constant inside a cell.

\section{Some Numerical Flux Functions}

In the above sections we saw how to contruct numerical flux functions
based on the eigensystem of the flux Jacobian. We don't always need to
use the full eigensystem and can often create other flux functions
that may be useful in some applications. We discuss two of these
below. There are several others for specific equation systems which we
will look at in later sections. Note that in all cases we must ensure
the flux-jump and the state-jump conditions are satisfied.

\subsection{Central Flux}

In this we simply choose the fluctuations to be
\begin{align}
  A^{\pm} \Delta Q_{R,L} = \frac{1}{2} \left[ F(Q_R) - F(Q_L) \right].
\end{align}
Clearly, this choice satisfies the flux-jump condition. With this, the
numerical flux is simply
\begin{align}
  G(Q_R, Q_L) = \frac{1}{2} \left[ F(Q_R) + F(Q_L) \right].
\end{align}
In general, this choice of numerical flux is not a good one: it has no
numerical damping and hence leads to schemes that are unstable or
develop high-$k$ noise, specially as the flow structures get to the
grid size.

\subsection{Lax Flux}

Lax fluxes are another universal choice in which we only need an
estimate of the largest absolute eigenvalue. This is much easier to
compute than the complete eigensystem. We define the fluctuations as
\begin{align}
  A^{\pm}\Delta Q_{R,L} = 
  \frac{1}{2} \left[ F(Q_R) - F(Q_L) \right]
  \pm  \frac{| \lambda |}{2} \left( Q_R - Q_L \right).
\end{align}
The second term in this expression adds numerical diffusion to the
scheme, damping high-$k$ modes to a certain extent (though even more
damping, provided by limiters, may be needed to capture shocks
properly). Here, $| \lambda |$ is an estimate of the maximum
eigenvalue at the interface. This can be computed, for example, as the
absolute value of the maximum eigenvalues computed from the left and
right states at the interface. Clearly, the flux-jump condition is
satisfied. With this, the numerical flux becomes
\begin{align}
  G(Q_R, Q_L) = \frac{1}{2} \left[ F(Q_R) + F(Q_L) \right]
  -  \frac{| \lambda |}{2} \left( Q_R - Q_L \right).
\end{align}
A consistent set of waves and eigenvalues can also be defined that
correspond to the Lax flux:
\begin{align}
  \mathcal{W}^{1,2}_{R,L} &= \frac{1}{2} \left( Q_R - Q_L \right) \mp \frac{1}{2 |\lambda |} \left[ F(Q_R) - F(Q_L) \right]
\end{align}
with $\lambda^{1,2} = \mp|\lambda |$.

For the Lax flux it is easy to see that there is a single intermediate
state given by
\begin{align}
  Q^* = \frac{1}{2}\left( Q_R + Q_L\right) - \frac{1}{2 |\lambda |} \left[ F(Q_R) - F(Q_L) \right].
\end{align}

The Lax flux, in a sense, represents the opposite of the central flux:
it adds \emph{too much} diffusion as opposed to no diffusion at all in
the central flux. However, the Lax flux is often useful, specially as
a fall-back numerical flux when positivity is violated, for example,
or the eigensystem is too complicated to construct.
